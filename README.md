# UMKMHub

Platform E-Commerce UMKM berbasis React.js yang dikembangkan sebagai Capstone Project untuk membantu pelaku Usaha Mikro, Kecil, dan Menengah (UMKM) memasarkan produk secara digital dan memperluas jangkauan pasar melalui teknologi web modern.

---

## 📌 Tentang Proyek

UMKMHub adalah aplikasi marketplace yang dirancang untuk menghubungkan pelaku UMKM dengan pelanggan secara online. Platform ini memungkinkan pengguna menjelajahi produk, melakukan pencarian, mengelola keranjang belanja, serta melakukan transaksi secara digital.

Project ini masih berada pada tahap pengembangan awal (Early Development Stage).

---

## 🎯 Latar Belakang

Banyak UMKM masih menghadapi kendala dalam pemasaran digital dan pengelolaan penjualan secara online. Oleh karena itu, UMKMHub hadir sebagai solusi untuk membantu pelaku usaha menjangkau lebih banyak pelanggan melalui platform e-commerce yang mudah digunakan.

---

## 🚀 Tujuan Proyek

- Mendukung digitalisasi UMKM.
- Mempermudah proses jual beli produk lokal.
- Meningkatkan akses pasar bagi pelaku UMKM.
- Menerapkan kolaborasi tim menggunakan Git dan GitHub.
- Mengimplementasikan pengembangan aplikasi web menggunakan React.js.
